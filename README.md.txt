# StyleAura - Online Fashion Store

An enterprise-grade e-commerce web application built using Java Servlets, JSP, HTML5, CSS3 (Bootstrap 5), and Jakarta EE.

## Features
* Product Catalog & Search functionality
* Interactive Shopping Cart management
* Checkout and Order Confirmation system
* Fully responsive UI built with Bootstrap 5

## Tech Stack
* **Backend:** Java Servlets (Jakarta EE)
* **Frontend:** JSP, HTML5, CSS3, Bootstrap 5
* **Server:** Apache Tomcat 10+
